02 · 完整分析

命盘与大运流年总报告

按固定流程分析旺衰、命格与喜忌，解读八步大运和五个流年。生成时向你的模型供应商发送命盘依据，分两次请求，费用由自己的 API 账户承担。

  2. 2 解读命盘与命格

  4. 4 围绕报告追问

03 · 基于这份报告

继续问你的命盘

助手沿用同一命盘：确认问题 → 核对原局 → 合参运年 → 解释条件 → 给出建议。可以追问报告窗口以外的年份。

每次回答调用你的模型；对话仅保留在本地内存。

BRING YOUR OWN KEY

连接你自己的模型。

选好供应商、填入密钥，点击一次完成测试与接入。离线排盘不需要这一步。

前往供应商获取密钥 ↗

密钥仅保留在本地服务内存中，重启后需要重新填写，不写入浏览器存储或文件。自定义本机接口可留空。

测试会发送一句简短请求，可能产生少量 API 费用。自定义服务需支持 Chat Completions 和 JSON 输出。

隐私与连接说明

没有平台账号，没有遥测。生成解读时发送计算事实、解释规则；追问还会发送问题、报告和最近对话。原始生日表单不直接发送，但命盘和交运时间仍可反推出个人资料。密钥仅用于所选供应商认证。命盘事实仍可能透露个人信息，请只连接你信任的供应商。

供应商可能按其条款保留请求。第三方转发地址会收到你的密钥，请核对地址；本地服务仅供自己使用，不应开放到公网。
