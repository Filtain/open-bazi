# Open Bazi v0.1.0 Demo

首个开源本地演示版。下载源码后安装Python 3.12或以上，运行 `python3 start.py`。

包含离线四柱、十神、藏干、五行主气计数、大运及所选流年；支持历史夏令时核对与农历输入。模型连接预置DeepSeek、通义千问北京地域，并支持自定义兼容接口。密钥保存在本地服务内存，AI费用由使用者自己的账号承担。

已通过22项本地自动化测试和桌面、手机浏览器流程检查。运行依赖扫描未发现已知漏洞。真实模型调用仍需使用者用自己的Key验证；Docker和Windows桌面运行尚未实测。

这是预发布演示版，需要准确出生时刻；尚无未知时刻候选、太阳时、完整格局喜忌、追问、记录数据库或免Python桌面安装包。只供单机自用，不应直接开放公网。
