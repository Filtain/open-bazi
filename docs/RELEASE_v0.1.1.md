# Open Bazi v0.1.1 Demo

修复模型连接诊断与密钥粘贴体验。

- DeepSeek 401明确显示认证失败，不再混用通义的地域提示；402单独提示余额不足。
- 自动去除误带的Bearer前缀、外层英文引号和首尾空白。
- 调用前检测疑似打码内容、内部空白、不可见字符及误粘贴的网址。
- 错误响应不回显输入密钥或供应商原始错误正文。
- 37项本地测试通过，包括模拟供应商认证错误和密钥格式处理。真实账号认证仍需用户使用自己的Key验证。

下载解压后使用Python 3.12或以上运行 `python3 start.py`。已有服务需停止并重新启动，再刷新页面。此版本仍为单机自用预发布演示版。
