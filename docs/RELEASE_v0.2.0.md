# v0.2.0 · 完整报告与命盘对话

这次将原来仅讲术语的解读升级为完整分析流程：

- 离线规则初读：月令、通根、透干、格局候选与合冲刑害。
- 命盘六节分析，覆盖旺衰、命格、喜忌、事业财富和情感相处。
- 八步大运、五个流年的逐段解释与行动建议，交运年按实际时间分段。
- 基于同一命盘的聊天，支持追问新的年份，后台先重新计算再回答。
- 两阶段生成，后半部分失败可以续接；完整流程和必需引用验证。
- 结果导出包含命盘、报告和对话，不包含密钥。

保持本地运行与用户自带 API。旧版密钥复制修复继续保留。升级后请重新连接模型，服务重启会清空内存连接和报告。

传统推演采用明确规则和条件判断；结构验证不等于语义正确性或预测有效性。暂不支持特殊格局的完整推断、流月流日、未知时刻候选、真太阳时、持久化历史或桌面安装包。

验证：自动化测试使用合成数据和模拟供应商；浏览器验证本机模拟模型下的完整报告、聊天、导出、旧命盘拦截、纯文本展示及手机布局，不消耗真实模型额度。真实模型文案质量仍受所选模型影响。
