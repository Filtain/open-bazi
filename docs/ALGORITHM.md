# 排盘算法口径（v0.2 沿用 v0.1 的历法策略）

历法核心使用 [6tail/lunar-python](https://github.com/6tail/lunar-python) 1.4.9。时区以项目固定的 tzdata 版本为准，返回结果记录策略和依赖版本。

1. 校验公历或农历日期。农历转换后核对年月日及闰月；不代填出生时刻。
2. 若选择历史钟表时间，以 Asia/Shanghai 解析；跳过的时刻拒绝，重复时刻要求选择第一次或第二次。转换成固定UTC+08时间。
3. 将同一实际时刻的UTC+08日期传给历法库，立春与十二节采用时刻边界，不使用农历初一作为月柱边界。
4. `EightChar.setSect(1)` 采用23点换日及一致的时干口径。
5. 十神相对原局日主计算。五行按天干和地支主气各计一次，共八项；不声称计数能判定强弱。
6. 阳男阴女顺行，阴男阳女逆行。未提供传统参数时省略大运，不猜测。
7. `getYun(gender, 2)` 取得分钟制起运分解：4320分钟折一年，360分钟折一月，12分钟折一日，剩余每分钟折两小时。按年、月、日、小时顺序加到出生标准时间，月末日期向当月末日截断。
8. 第一步大运取月柱顺逆推进一位，后续每十个公历年，从首运实际起点锚定计算，起止左闭右开。
9. 流年按所选年份干支和立春时刻展示，十神相对出生盘日主。

可复现样例：1988-02-15 23:30 东八区为戊辰、甲寅、辛丑、戊子。2022-03-09 20:51、传统参数男、分钟制起运为2030-12-12 06:51东八区。1991-08-13中国钟表时间17:20，对应标准时间16:20。

这些测试验证实现与选定口径，不是对命理预测有效性的验证。古代历法、完整地域历史时制、太阳时和未知时刻候选不在本版范围内。

结构证据、格局候选、运年叠加和问答时间范围见 [解读 SOP](READING_SOP.md)。历法策略未因新增解读功能而更改。
